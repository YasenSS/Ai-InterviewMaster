# InterviewMaster 验收清单

## M0

- `docker compose config --quiet` 通过。
- API `/health` 与 `/ready` 可访问。

## M1

- 注册/登录并取得 JWT；不同用户的数据互不可见。
- 创建 JD 后返回能力标签。
- PDF/DOCX/TXT 通过预签名 URL 上传，Worker 经 Tika 解析并写入 facts、chunks 与 pgvector 基线向量。

## M2

- 已解析简历可生成五题结构化题集。
- 创建文字面试后可逐题回答、刷新恢复，并在最后一题后进入 completed。

## M3

- 完成的面试可生成总体与逐题评分、批评、Golden Answer、证据和质量门禁。
- 重复查询同一会话复用同一报告。

## Beta

- 面经画像接口提供本地降级结果，外部检索供应商可替换。
- `docker compose --profile beta up -d asr` 启动本地 Whisper；ASR 接口投递任务，Worker 转写并可通过 `/api/v1/tasks/{id}` 查询结果。
