## P0 — 不上线不行（阻断级）

### AI 核心（最大缺口）

- [ ] **定义模型能力接口**：`ChatModel`（Generate/Stream）、`EmbeddingModel`、`Reranker`、`SpeechToTextModel`，业务层不感知供应商 SDK
- [ ] **接入至少一个真实 LLM Provider**（OpenAI 兼容 / 国内平台 / 本地模型），含超时、重试、降级
- [ ] **Prompt 版本化**：`prompt_key + prompt_version`，模板落 `prompts/` 目录或 DB，可回滚
- [ ] **出题接真模型**：替换 `createquestionsetlogic.go` 中固定 5 题，基于简历事实 + JD 生成，带证据引用
- [ ] **评分接真模型**：替换 `getinterviewreportlogic.go` 中字数评分，按方案拆 Intent→Evidence→Evaluation→Critique 多阶段
- [ ] **报告接真模型**：逐题点评、Golden Answer、训练计划由模型生成，引用可定位到简历原文
- [ ] **真实 Embedding**：替换 `resumeparse.go` 中 SHA-256 假向量，接真 embedding 服务，固定 Embedding Space 版本
- [ ] **检索链路真召回**：pgvector 按 `workspace_id` 过滤的向量检索 + 全文/关键词混合
- [ ] **结构化输出校验**：模型输出先入 Go Struct 并过 JSON Schema；失败只允许一次修复重试，仍失败则明确报错

### 安全底线

- [ ] **密码哈希换 Argon2id**（现状 bcrypt）
- [ ] **CSRF/Origin 校验**（当前仅 SameSite Cookie，无显式 CSRF token/Origin 校验）
- [ ] **基础 API 限流**：登录接口防暴力破解、业务接口按用户限流
- [ ] **文件病毒扫描**（现仅验 magic bytes + 大小，方案要求病毒扫描）
- [ ] **用户数据导出/删除入口**：删除简历、会话、音频、账户，记录删除任务状态（方案列为 MVP 必交付）

## P1 — 体验与稳定（上线后应尽快补）

### AI 治理

- [ ] **模型调用审计**：`model_invocations` 表，记录 provider/model/prompt_key/version/输入输出哈希/token/费用/耗时/trace_id
- [ ] **成本控制**：每次调用最大输入/输出、超时、按用户并发限制；资源版本缓存防重复生成
- [ ] **额度体系**：工作区日/月预算软硬阈值；超软阈值降级、超硬阈值拒绝
- [ ] **防 Prompt Injection**：系统规则/任务/证据/用户输入分层隔离；评测集含恶意提示用例

### 可观测性

- [ ] **OTel 真正接通**：部署 Collector + Jaeger/Prometheus，生产开启
- [ ] **AI 专项指标**：首 Token 时间、总耗时、Token 消耗、费用、结构化输出失败率、检索空结果率
- [ ] **告警**：登录异常、跨工作区拒绝激增、队列堆积、模型错误率飙升、单用户费用异常

### 测试补齐

- [ ] **真实 PG 集成测试**：事务、权限过滤、向量/全文 SQL（用带 pgvector 的容器）
- [ ] **队列测试**：重复投递、Worker 崩溃、超时、重试、死信恢复
- [ ] **E2E 全流程**：注册→上传→分析→建岗→出题→模拟→报告
- [ ] **安全测试**：水平越权、恶意文件、签名 URL 过期、Prompt Injection、日志泄密
- [ ] **AI Golden Dataset 评测集**：版本化，Prompt/模型升级必跑回归，低于基线不上线
